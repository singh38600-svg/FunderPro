# Rohit Trader Challenge Dashboard

A Vercel-ready React/Vite dashboard using fictional account data and an original brand identity. It is designed as a personal UI concept inspired by modern prop-trading dashboards.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Vercel
Import the GitHub repository into Vercel. Vercel should detect Vite automatically.

## Important
This project is not affiliated with FunderPro and does not reproduce FunderPro's official logo, account credentials, communications, or official decision records. The account numbers, trades, review findings, and status are fictional.
